ALO PORTFOLIO — HTML/CSS/JavaScript

HOW TO OPEN
1. Extract this folder.
2. Open the folder in VS Code.
3. Open index.html in your browser (or use the VS Code Live Server extension).

BEFORE PUBLISHING
1. In index.html, replace YOUR_EMAIL@example.com with your real email.
2. Replace YOUR_LINKEDIN_URL with your real LinkedIn profile URL.
3. Check every project description and edit anything that doesn't match your experience.
4. If you want to offer a CV download, add your CV as cv.pdf in this folder and add a link to it in the HTML.

This project uses plain HTML, CSS, and JavaScript. No React, Node, or Laravel server is needed to preview it.
